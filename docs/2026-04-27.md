## 2. Supervisor 응답 빈 답변 분석

대시보드에서 "현재 한국에서 주목할 만한 주식 알려줘" 질문에 빈 답변이 도착.

### 원인
**Anthropic API 분당 30,000 입력 토큰 제한 초과** (`claude-sonnet-4-6`).

### 발생 흐름
1. 1차 질문(삼성전자 주가) 종료 후 8초 만에 2차 질문 발사
2. DataCollector가 `get_theme_group_list` 호출 → 응답이 매우 큼
3. 1분 토큰 윈도우 안에 누적 → DataCollector 429
4. Supervisor 본인도 다음 Claude 호출 시 429 (재시도 3회 모두 실패)
5. `RateLimitError` 예외 → 큐에 누적된 텍스트 없음 → 빈 응답으로 종료

### 결론
구조적 개선 후보:
- 대시보드 큐로 동시 1개 채팅만 실행
- 하위 에이전트 모델을 Haiku로 다운그레이드
- Tool result 사이즈 제한 (예: `get_theme_group_list` 상위 N개)
- 빈 응답 감지 시 명시적 오류 표시

## 3. 신정재 특강 PDF 분석

### PDF 처리
- 입력: `신정재특강정리노트.pdf` (21페이지, 이미지 기반 스캔)
- pypdf로 텍스트 추출 시 빈 결과 (이미지 PDF)
- pymupdf로 페이지를 PNG 렌더링 → 멀티모달 Read로 페이지별 분석

### 추출한 핵심 룰

**매수 타이밍**: 14:50–15:20 (종가 30분 전), 다음날 갭상승/시초가 매도

**6가지 종목 선정 기준**:
1. 재료(뉴스/공시) 존재 + 트렌드 부합
2. 거래대금/거래량 surge (최근 평균 대비 1.5배+)
3. 매물대(전고점)와 이격 -8% ~ -3%가 이상적
4. 캔들 위꼬리 짧은 양봉
5. 충분한 기간 조정 후 회복 (N자/W형)
6. 외인·기관 양매수 (특히 대형주)

**청산 룰**:
- ★ 시간외 하락 → 즉시 매도
- ★ 매수 평단 이탈 → 즉시 손절
- 수익 2-3% → 일부 익절
- 시초가 수익 → 1/3 매도, 9:05 이내 전량
- 물타기 절대 금지

**시장 필터**:
- KOSPI 오늘 -1.5% 이하 → 종베 비추천
- KOSPI 5일 누적 -3% 이하 → 추세 약세

## 4. `closing_bet_mcp` — 두 단계 설계

### 1차 설계 (MCP에 데이터 fetching 포함)
포트 8060에 새 MCP 서버를 만들고 안에서 직접 FinanceDataReader/DART/Naver News 호출.

**문제**:
- 기존 `kiwoom-market-mcp`/`naver-news-mcp` 등과 데이터 fetching 중복
- pykrx KRX 차단으로 일부 데이터 미동작
- 외인/기관 데이터 못 가져옴

### 2차 설계 (사용자 제안 채택, **옵션 B**)
**MCP는 순수 계산기로 슬림화, 데이터 수집은 DataCollector가 기존 MCP로 처리.**

이유:
- 데이터 fetching 중복 제거
- 스코어링 공식이 결정론적 코드로 남음 (백테스트 가능)
- 트렌드 키워드 사전 같은 운영 데이터를 코드로 관리
- DataCollector는 데이터 수집·전달, closing_bet_mcp는 점수 계산 — 역할 분리 명확

## 5. `closing_bet_mcp` 최종 구조 (옵션 B)

### 파일 구성
```
src/mcp_servers/closing_bet_mcp/
├── __init__.py
├── server.py        # FastMCP 서버 (포트 8060), 8개 도구
├── catalyst.py      # 기준 1: 트렌드 매칭 + 재료 점수 (순수)
├── scorer.py        # 기준 2-6: 거래량/매물대/캔들/조정/외인기관 (순수)
└── exit_rules.py    # 청산 신호 + 시장 필터 (순수)
```

### MCP Tools (모두 결정론, 외부 호출 0)
| Tool | 입력 | 출력 |
|------|------|------|
| `score_catalyst_text` | news_titles, disclosure_titles | 재료 점수, 매칭 트렌드 |
| `score_technical_indicators` | ohlcv 90봉, foreign_net_5d, institutional_net_5d | 5개 sub-score + composite |
| `score_stock_combined` | 위 모두 합쳐서 한 번에 | composite (재료 30% + 기술 70%) |
| `rank_candidates` | 채점된 종목 리스트 | top_n 정렬, 시총 작은 순 우선 |
| `check_market_filter` | kospi_today_pct, 5d_pct | ok/false + 이유 |
| `check_exit_signal` | entry/current/ah price | HOLD/PARTIAL_SELL/SELL_ALL/STOP_LOSS |
| `match_trend_keywords` | texts | 매칭된 트렌드/키워드 |
| `get_strategy_rules` | (없음) | 전체 룰 + 워크플로우 가이드 |

### 점수 공식 (백테스트 가능)
- **거래량 surge**: 오늘 거래대금 / 20일 평균 — 1배=0점, 5배=100점 선형
- **저항 이격**: 60일 고점과 -8% ~ -3% 구간 = 100점, 그 외 감점
- **캔들 모양**: `(고가 - max(시,종)) / (고가-저가)` 위꼬리 비율, 양봉 +10
- **조정**: 60일 고점 대비 drawdown × 0.7 + 회복률 × 0.3
- **외인/기관**: 5일 누적 순매수 부호 — 양쪽 매수 100, 한쪽 60, 양쪽 매도 0
- **재료**: 뉴스 N건×4 + 공시 +15 + 트렌드 매칭 트렌드당 +15

### 트렌드 키워드 사전 (`catalyst.py`)
AI/반도체 · 2차전지 · 방산 · 바이오 · 원전/전력 · 로봇 · 조선 · 양자
(운영 중 코드 수정으로 갱신)

### 한국어/영어 키 양쪽 호환
ohlcv 입력에서 `시가/고가/저가/종가/거래량/거래대금` 또는 `open/high/low/close/volume/value` 모두 인식.
