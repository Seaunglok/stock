이제 A2A 관련 타입은 모두 `src/a2a_integration/` 한 디렉터리에 모인다.

## 3. 종베(closing-bet) 설정 정합성 마무리

어제 작성했지만 일부 설정 파일에 미반영 상태로 남아 있던 항목을 합류시켰다.

### `src/claude_agents/base/mcp_config.py`
- `STANDARD_MCP_SERVERS` 에 `closing-bet-mcp: http://localhost:8060/mcp` 추가
- `AGENT_MCP_SERVERS["data_collector"]` 에 추가:
  - `investor-domain` (외인/기관)
  - `financial-analysis-mcp` (DART 공시)
  - `closing-bet-mcp` (점수 계산)

### `src/claude_agents/base/prompts.py`
DataCollector 시스템 프롬프트 끝에 **종가배팅 모드 5단계 워크플로우** 섹션 추가:
1. 시장 필터 (`check_market_filter`)
2. 유니버스 선정 (`get_volume_ranking`)
3. 종목별 데이터 수집 (OHLCV 90일 / 뉴스 3일 / 외인기관 5일 / 공시)
4. 점수화 (`score_stock_combined`)
5. 정렬 (`rank_candidates`, top_n=5, min_score=50)

핵심 원칙: 점수는 **닫힌 공식** — Claude 가 임의 평가 금지.

### `run_mcp_local.py`
`SERVERS` 리스트에 `("closing_bet", "src.mcp_servers.closing_bet_mcp.server")` 추가.

### `check_status.py`
`SERVICES` 리스트에 `("closing-bet", 8060, "mcp", ...)` 추가 (총 15개 서비스).

### `src/claude_agents/supervisor/executor.py`
`call_data_collector` tool 의 `query` description 예시에서 종목명("삼성전자") 제거 → 일반화.
Supervisor 가 특정 종목 prior 없이 더 자유롭게 위임할 수 있도록 정리.
