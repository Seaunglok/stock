## 1. MCP 도구 결과 truncate 가드

### 배경
04-29 회고에 적었던 "Tool result 사이즈 제한" 후속.
`get_theme_group_list` 같은 응답은 수십만 자에 달해 Claude 컨텍스트와 분당 입력 토큰 한도를 동시에 잡아먹는다.
DataCollector가 한 번 호출하면 다음 호출에서 즉시 429를 맞는 패턴.

### 조치 — [src/claude_agents/base/mcp_client.py:23-46](src/claude_agents/base/mcp_client.py#L23-L46)

`MCPManager._truncate_if_needed`를 추가해 모든 도구 호출 결과를 **기본 30,000자**로 자른다.

- 환경변수 `MCP_TOOL_RESULT_MAX_CHARS`로 오버라이드 (0/음수면 비활성화)
- 잘릴 때는 안내 문구를 덧붙여 Claude에게 "더 좁은 필터로 재호출하라"는 신호를 명시적으로 전달
- `logger.warning`으로 원본/유지/생략 글자수를 기록 → 어떤 도구가 자주 잘리는지 사후 추적 가능

핵심은 단순 잘라내기가 아니라 **Claude에게 우회 경로(filter/limit 재호출)를 알려주는 것**.
Tool result를 `is_error: true`로 만들지는 않았다 — 자른 결과 자체도 부분적으로 유효하기 때문에 일반 결과로 두고 안내만 끼워 넣는다.

## 2. 백테스트 스크립트 영속화 + 분석 확장

### 배경
`scripts/backtest_closing_bet.py`는 04-29 시점에 stdout만 출력했고, 실행 결과를 비교/리뷰할 수 있는 산출물이 없었다.
점수 임계값 튜닝을 본격적으로 하려면 결과를 파일로 남기고, 어떤 sub-component가 수익에 기여했는지를 봐야 한다.

### 조치 — [scripts/backtest_closing_bet.py](scripts/backtest_closing_bet.py)

기존 `simulate()`가 `(date, code, score, ret)` 튜플만 반환하던 것을
**rich dict (components / breakdown 포함)** 로 확장하고,
출력단을 4개 모드로 분리했다.

| 옵션 | 산출물 | 용도 |
|------|--------|------|
| `--out PATH.md` | 마크다운 요약 (점수구간별 승률 표) | 기간별 비교 |
| `--csv PATH.csv` | 픽별 raw 데이터 | 외부 도구 분석 |
| `--html PATH.html` | plotly 캔들차트 (BUY/SELL 마커) | 시각 검증 |
| `--top-stocks` | 수익률 상위 종목 + 승자/패자 sub-component 비교 | 어떤 조건이 먹히는지 |

`_summarize()`로 본문 생성 로직을 분리해 stdout / 파일이 동일 포맷을 공유한다.

### 핵심 신규 기능 — `analyze_top_stocks()`

기간 내 픽을 종목별로 묶어 평균수익률 상위 K개를 뽑고, **승자(ret>0) vs 패자의 sub-component 평균 점수를 비교**해
어떤 기준(거래대금/저항이격/캔들/조정회복)이 실제 수익을 만들었는지 데이터로 보여준다.

> 예시 출력 — [docs/backtest_30d_top.md](docs/backtest_30d_top.md)
> 30일 구간에서는 "캔들 모양"이 승자에서 오히려 -16.2점 낮게 나왔다 →
> 위꼬리 큰 종목(=상승 직후 매도세)이 의외로 익일 시초가에서 더 잘 나오는 역전 현상.
> 표본이 작아 단정은 어렵지만, 추후 점수 가중치를 재조정할 단서가 됨.

## 3. 백테스트 실행 결과

### 30일 구간 — [docs/backtest_30d.md](docs/backtest_30d.md)
- 기간: 2025-11-01 ~ 2026-04-30, 26종목, 임계값 50, top_n 5
- **38건 / 승률 71.1% / 평균수익 +0.72%**
- 50–60점 구간이 33건으로 대부분, 60–70점 구간 5건은 평균 +1.38%

### 장기 구간 — [docs/backtest_latest.md](docs/backtest_latest.md)
- 기간: 2025-07-24 ~ 2026-04-30 (~9개월)
- **197건 / 승률 54.3% / 평균수익 +0.48%**
- 70–80점 구간 5건은 승률 40%로 오히려 저조 → **고점수 = 고수익이 아님** 확인

### 해석
30일 구간의 71.1%는 표본이 적고 최근 강세장에 편향됐을 가능성이 크다.
장기 표본 54.3% 쪽이 현실적인 베이스라인이고, 점수 구간별 단조성이 깨진 것은
**현재 composite() 가중치가 실제 수익률과 정렬되지 않았다**는 신호로 본다.

후속: 종목별/구간별 sub-component 회귀로 가중치 재조정 — 다음 작업에서.

04-29의 종베 데모는 어디까지나 동작 확인이었고, 실제 알파를 만들려면 점수 자체를 다시 짜야 한다는 게 데이터로 드러났다.
