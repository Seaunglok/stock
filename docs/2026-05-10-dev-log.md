## 분석 (1차) — 승률 저하 원인 진단

`scorer.py`, `exit_rules.py`, `direct_closing_bet.py` 전체 분석 후 도출된 5가지 핵심 문제:

| # | 문제 | 영향 |
|---|------|------|
| 1 | 청산 시 현재가로 pykrx 전일종가 사용 → PnL 항상 ≈ 0, 손절/익절 미작동 | 치명적 |
| 2 | 재료 없는 종목도 catalyst_weight=0.30 적용 → cat.score=0이 희석 | 높음 |
| 3 | 종목 universe TOP_N=30 (거래대금) → 대형주 위주, 셋업 부족 | 중간 |
| 4 | advance_ratio·레짐 분류 함수 존재하나 실제 phase_selection에 미연결 | 중간 |
| 5 | 손절 임계치 -1% → 노이즈 구간에서 빈번 트리거 | 중간 |

### Fix 1 — 실시간 현재가 소스 교체
`_try_get_realtime_price(symbol)`: kiwoom-market-mcp → trading-domain 순으로 시도,
시세 키워드(`current_price`, `현재가`, `last_price`)로 동적 탐색.

### Fix 2 — 재료 없음 시 catalyst_weight=0
```python
cat_weight = 0.30 if cat.has_catalyst else 0.0
composite = cat.score * cat_weight + tech.composite() * (1.0 - cat_weight)
```
재료 있을 때만 뉴스 가중치를 주고, 없으면 기술적 점수 100%.

### Fix 3 — Universe 30→50
`TOP_N_STOCKS = 50` — 거래대금 상위 50개로 확장, 중형주 셋업 기회 포함.

### Fix 4 — advance_ratio + 레짐 분류 실제 연결
`get_advance_ratio()` pykrx 헬퍼 추가, `phase_selection()`에서 호출.
`classify_regime(kospi_pct, advance_ratio)` → weak 시 선별 스킵.
`exit_rules.py`에 `classify_regime()` 순수 함수 추가 (weak/neutral/strong).

### Fix 5 — 손절 임계치 -1% → -3%
`exit_rules.py` `evaluate_exit()` 내 `entry_price * 0.99` → `entry_price * 0.97`.
종가매매 특성상 다음날 시초 ±2% 변동은 정상 범위.

## 구현 (2차) — 세부 내용

### Fix 1 — 섹터 분산 제한 (`apply_sector_limit`)
```python
MAX_PER_SECTOR = 2  # 섹터당 최대 편입 종목 수

def apply_sector_limit(candidates_pool, sector_map, max_per_sector=MAX_PER_SECTOR):
    sector_count: dict[str, int] = {}
    selected: list[dict] = []
    for c in candidates_pool:
        sector = sector_map.get(c["symbol"], "기타")
        if sector_count.get(sector, 0) < max_per_sector:
            selected.append({**c, "sector": sector})
            sector_count[sector] = sector_count.get(sector, 0) + 1
        if len(selected) >= TOP_CANDIDATES:
            break
    return selected
```
`_load_sector_map()`: FinanceDataReader `StockListing("KOSPI")`로 섹터 데이터 로드,
일별 캐시(`_sector_map_YYYYMMDD.json`) 적용으로 반복 호출 방지.

### Fix 3 — 당일 갭업 이벤트 필터 (`_has_today_gap`)
```python
def _has_today_gap(ohlcv: list[dict], threshold_pct: float = 4.0) -> bool:
    if len(ohlcv) < 2:
        return False
    prev = ohlcv[-2]["close"]
    curr = ohlcv[-1]["close"]
    return prev > 0 and (curr - prev) / prev * 100 >= threshold_pct
```
당일 전일 대비 +4% 이상 갭 종목은 선별에서 제외 (`gap_filtered` 카운터로 추적).

### Fix 4 — 미국 야간 지수 게이트 (`get_overnight_us_change`)
```python
def get_overnight_us_change() -> tuple[float, float]:
    # FinanceDataReader로 S&P500(US500), NASDAQ 전일 대비 등락률 계산
    return sp_pct, nq_pct  # (float, float)
```
`phase_selection()` 상단에서 호출: `sp_pct <= US_MARKET_WEAK_THR AND nq_pct <= US_MARKET_WEAK_THR`
(두 지수 모두 -1.5% 이하) → 선별 전면 중단.

### Fix 6 — 시간외 단일가 phase 추가 (`phase_after_hours`)
- **18:05** 스케줄 추가 (`SCHEDULE` 리스트)
- `_try_get_after_hours_price(symbol)`: kiwoom-market-mcp에서 시간외 현재가 조회
- `evaluate_exit(..., after_hours_price=ah_price)` 결과를 `after_hours_signals` 상태로 저장
- `phase_sell()`이 09:00에 이 신호를 참조 → `after_hours_price` 파라미터 전달
