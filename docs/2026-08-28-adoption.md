# 채택 구성 적용 + 모의운용 개시 (2026-08-28)

[워크포워드 검증](2026-08-28-walkforward.md)이 선언 기준을 충족해, 라이브 코드를 검증된 구성으로
맞추고 모의운용을 시작했다. **신규진입은 여전히 정지**다 — 모의운용 통과 전까지 해제하지 않는다.

## 1. 청산 사다리 교체

| | 이전 | 지금 |
|---|---|---|
| 부분익절 30% | ON | **OFF** |
| ATR 트레일 래칫 | ON | **OFF** ← 범인 |
| MA120 이탈 | ON | ON |
| 시간청산 | 60영업일 | **120영업일** |
| 하드손절 10% | ON | ON (스위치 없음) |
| 외인 5일 순매도 | ON | **OFF** |

`exit_decision(exits=...)` 스위치를 추가했다. 백테스트 하니스의 동명 인자와 **같은 토큰 규약**을
쓰고, 갈리면 실패하는 테스트를 걸었다(`test_live_and_backtest_share_exit_token_vocabulary`).

**하드손절은 스위치에 없다.** 전략 선택지가 아니라 위험 바닥이기 때문이다 — 백테스트는 항상
모델가 체결을 가정하지만 실거래엔 하한가·거래정지가 있다. MA120 이 살아있으면 거의 발동하지
않으므로(비용 0의 보험) 끌 이유가 없다.

**외인 청산을 껐다.** ka10008 이력이 2026-05 부터라 12년 검증이 불가능하고, 워크포워드가 채택한
구성에도 없다. 검증본에 없는 규칙이 라이브에서만 발동하는 상태는 08-25 KB금융 오청산의
구조 그 자체다.

트레일을 끄면 래칫 계산도 멈춘다. 계산만 돌려두면 일지·알림에 **쓰이지 않는 손절선**이 표시돼
운영자가 있는 줄 알게 된다.

## 2. 연간 재선택 — 문서가 아니라 명령

워크포워드가 잰 것은 특정 규칙의 성적이 아니라 **"매년 학습구간으로 다시 고르는 절차"** 의
성적이다(8폴드에서 4종이 뽑혔다). 절차를 실행하지 않으면 검증된 것과 다른 전략을 돌리게 된다.

```bash
python scripts/walkforward_trend.py --select-now --exposure 0.5
```

후보 격자·선택 규칙은 워크포워드와 **같은 것을 쓴다**(`GRID`/`select`). 갈리면 검증이 무효다.
출력이 `.env` 형식으로 나오므로 그대로 반영하고 `tests/test_trend_config.py` 스냅샷을 갱신한다.

## 3. 모의운용 (`scripts/trend_paper.py`)

**브로커를 전혀 호출하지 않는다.** 키움 MCP 를 쓰지 않으므로 주문이 나갈 경로 자체가 없다.

**증분 상태를 두지 않는다.** 매일 `paper_start ~ 오늘` 을 **검증 하니스로 통째로 재실행**해 장부를
만든다. 상태 파일 손상이 조용한 오류가 되는 경로를 없애고(08-17 state.json 사고와 같은 종류),
무엇보다 **검증에 쓴 코드와 같은 코드**가 돈다. 모의운용이 백테스트와 다른 로직으로 돌면
그 결과는 아무것도 검증하지 못한다.

평일 16:10 자동 실행(`TrendPaperDaily`), 기록은 `data/trend_follow/paper_log.jsonl`.

**개시 전 확인용 소급 실행** — 최근 폭락 구간(2026-06-01~08-27, KOSPI 고점 -26.5%):

```
진입 15건 · 청산 15건 · 승률 0.0% · 평균 -10.00%(전부 하드손절)
누적 -3.32% · MDD 3.40% · 평균 동시보유 1.3
```

전부 손절이지만 **노출 50%·종목당 2.5%** 라 계좌 타격은 -3.32% 다. 같은 기간 실계좌는
risk 1.5%·슬롯 5 구성으로 훨씬 큰 손실을 냈다. 사이징이 왜 위험 결정인지 보여주는 대비다.

**검증 못 하는 것**: 슬리피지·부분체결·호가공백. 진입이 익일 시가 가정이라 라이브 11:00 과
시각이 다르다. **모의운용이 좋다고 실계좌가 같다는 뜻이 아니다.**

## 4. 노출 결정 — 50%

프론티어에서 65%·50% 둘 다 기준을 충족했다. **50% 를 택한 근거**:

| | 65% | **50%** |
|---|---|---|
| MDD | 22.3% (기준 22.7%에 **0.4%p 여유**) | **17.4%** (5.3%p 여유) |
| MAR | 0.69 | **0.74** |
| 플러스 연도 | 5/8 | **6/8** |
| 누적 | +190.4% | +144.6% |

65% 는 기준선에 **거의 붙어 있다** — 추정 오차가 조금만 있어도 넘어간다. 기준을 아슬아슬하게
통과하는 값을 고르는 것은 기준에 맞춰 고르는 것과 다르지 않다. 50% 는 세 지표 모두 낫고,
손실 구간(누적 -598만원) 이후의 재개라 **낮은 쪽에서 시작해 단계적으로 올리는 것**이 맞다.

노출은 학습 대상이 아니라 위험 선호이므로, 올리려면 그 자체를 결정으로 남긴다.

## 현재 라이브 설정

```
사이징 notional 2.5% × 슬롯 20 = 노출 50%
청산   ma,hold (MA120 · 120영업일) · 하드손절 10% · 외인 off
게이트 레짐 MA60 · breadth 0.4 · 랭킹 composite · 눌림 MA20~+12%
진입   **정지** (TREND_ENTRY_HALT=true)
```
