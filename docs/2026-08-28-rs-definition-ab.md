[생존편향·12년 표본 문서](2026-08-28-survivorship-and-12y-sample.md) §②에서 **RS 게이트가
상승장 최대 억제 요인**으로 나왔다(단독탈락 1.90% → 7.54%). 지수가 +164.8% 오르면 60일
수익률로 지수를 이기기 어렵고, 추세추종이 가장 잘 들 국면에서 진입이 막힌다.

### 해석

RS 는 **억제 요인이었을 뿐 손실 원인이 아니었다.** ② 진단은 "왜 상승장에서 안 사는가"에
답했지만, 더 사게 만들어도(임계 -10%: 진입 3,194 → 3,974) 기대값은 오히려 나빠졌다.
막혀 있던 후보들이 좋은 후보가 아니었다는 뜻이다.

즉 문제는 진입 **필터의 강도**가 아니라 **후보 풀 전체의 질**이다. 게이트를 조정해 해결될
문제가 아니다.

## 부수: `residual_momentum` 이 항상 0을 반환하던 버그

첫 측정에서 잔차 모멘텀 변형이 **진입 0건**으로 나왔다. 결과가 아니라 함수 버그였다.

```python
resid = [y - (alpha + beta * x) for x, y in zip(mr, sr)]   # 적합 표본과 동일 구간
return round(sum(resid) / sd, 4)                            # ← 항상 0
```

절편이 있는 OLS 는 **적합 표본 위에서 잔차 합이 정확히 0** 이다. 같은 구간에서 적합하고 같은
구간에서 누적하면 결과는 정의상 0 이고(부동소수 오차만 남는다), 게이트로 쓰면 전 종목이 탈락한다.

원논문대로 **베타는 긴 추정구간(기본 3년)에서 잡고, 잔차 누적은 그 안의 최근 형성구간(기본 1년)
에서만** 재도록 고쳤다. 실데이터 검증에서 -27.9 ~ +40.4 범위의 값이 나온다(수정 전 전부 0.0000).

이 함수는 라이브 호출부가 0 이라 실거래 영향은 없었다. 회귀테스트 3건을 추가했다
(`test_residual_momentum_is_not_identically_zero` 등).

기존 테스트 `test_residual_momentum_discounts_pure_beta` 의 전제도 함께 고쳤다 —
**전 구간 상수 알파는 OLS 절편이 흡수**하므로 잔차가 0 이 되는 게 정상이다. 이 지표가 재는 것은
'자기 장기평균 대비 **최근** 초과분'이다. 알파를 최근 구간에만 주도록 바꿨다.

## 결론

진입 규칙 재설계의 첫 후보였던 RS 축은 **막다른 길**이다. 다음으로 검증할 것은 게이트가 아니라
후보 풀 자체 — 유니버스 정의(대형주 100 이 맞는가), 보유기간 시계, 청산 사다리다.
그때까지 신규진입은 정지 상태를 유지한다(`TREND_ENTRY_HALT=true`).
