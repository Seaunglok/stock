## 안전장치

- **`I3_DRY_RUN=true`(기본)**: 주문 도구를 부르지 않고 계획만 기록·텔레그램 알림. `I3_HALT=true` 면 매매 단계 정지.
- 판단은 15:35 이후만(장중 일봉 미완성). 오늘 일봉이 없으면(휴장·미갱신) 판단 안 함.
- 장기 이력(FDR)과 키움 최근 일봉이 겹치는 날 종가 차이 > 0.5% → 판단 중단 + critical.
- 계좌 조회 실패를 '보유 0' 으로 믿지 않는다 → 중단.
- 응답 불명 주문 재전송 금지 — 매매 후 잔고 대조로 확인, 다르면 critical.
- 하루 1회 멱등(같은 날 재실행 시 자산 이력 중복·이중 매매 없음). 판단이 4일 넘게 묵으면 매매 안 함.
- 단계 중 예외 → critical 알림 + 종료코드 1(조용히 끝나지 않는다).

## 알려진 한계

- 실전 체결은 매도가 시가(동시호가), 매수는 09:00 체결 직후 시장가 — 백테스트(다음 날 시가)와 약간 다르다.

- 낙폭 예산의 자산 이력은 실전 시작일부터 쌓인다(그 전 이력 없음 → 첫날 최고치 = 시작 자산).

  남았다**(새 서버는 바인딩 실패, 상태는 UP 으로 보임). `Stop-Process` 로 MCP 프로세스를 직접 내리고 start 했다.
  재시작 후엔 반드시 도구 스키마/응답으로 새 코드가 떴는지 확인할 것.
