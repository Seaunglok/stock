# 전략 연구소 잣대 선언 (2026-10-22, 측정 전)

## 배경

10-21 에 우리 추세추종이 KODEX200 단순보유에 두 구간 모두 진다는 것이 드러났다
([후보 비교](2026-10-21-candidate-data-comparison.md)). 운용자 목표: **버핏의 제1원칙("돈을 잃지
마라")을 지키면서 연 30~40%**. 연 30~40% 는 메달리온 수준이라 약속할 수 없지만, 지향점으로 두고
아래 잣대로 정직하게 잰다.

## 잣대 — 운용자 결정 (`scripts/strategy_lab.py` 코드 상수)

| | 기준 | 값 |
|---|---|---|
| ① | 최대 낙폭 (제1원칙) | **≤ 20%** |
| ② | 어느 한 해도 이보다 나쁘지 않을 것 | **≥ −10%** |
| ③ | 전체 구간 CAGR | **≥ KODEX200 단순보유 + 5%p** |
| ④ | 박스권(2015-07~2018-12)·강세장(2019-01~2026-08) **각 구간** CAGR | ≥ KODEX200 단순보유 |
| ⑤ | 파라미터 격자의 **중앙값**도 ①~④ 충족 | 가장 좋은 설정 하나가 아니라 '보통의 설정'으로 |
| 장기 | 장기 데이터가 있는 전략은 1998~2026(외환위기 직후·닷컴·금융위기)에서도 ①② | 격자 중앙값 |
| 지향 | CAGR 30% | 보고만 |

벤치마크 KODEX200 단순보유 자체(같은 체결·비용): **CAGR 16.8% · MDD 40.8% · 최악 연도 −24.2%(2022)**
→ ①② 를 못 지킨다. 목표를 숫자로 쓰면 **CAGR ≥ 21.8% 이면서 MDD ≤ 20%, 최악 연도 ≥ −10%**.

## 하니스 (`strategy_lab.py`)

- 체결: 신호일 종가 → 다음 날 시가. 비용 `trend_mcp.costs` 단일 소스(주식 매도만 거래세, ETF 없음).
- 예탁 3,852,844원 정수 주식수(소액 계좌 제약). 현금 이자 0(보수적).
- 구간 결과는 한 번 돌린 곡선을 잘라서 잰다(구간마다 다시 돌리면 진입 시점이 달라진다).
- 워크포워드 하니스(`walkforward_trend.py`)도 벤치마크를 KODEX200 으로 바꾸고 이 잣대를 함께 출력한다.

### 읽는 법

1. **막힌 곳은 수익이 아니라 제1원칙(MDD ≤ 20%)이다.** B·C 는 수익 목표(③ CAGR ≥ 21.8%)를
   넘었지만 낙폭이 40~60% 였다. 한 자산을 켜고 끄는 스위치형 전략은 급락(2020-03, 2022, 2026-10)이
   신호보다 빨라 낙폭을 20% 안으로 막지 못한다.
2. **10-21 에 좋아 보였던 'KODEX200 + MA60' 은 구간을 탄 것이었다.** 2019~26 만 보면 MDD 22.9% 였지만
   박스권까지 넣으면 CAGR 이 벤치보다 낮고(14.0% vs 16.8%), 장기(1998~)에선 MDD 45%.
3. 레버리지는 장기 스트레스에서 MDD 66~84% — '회복 불가능한 손실' 그 자체다.

### 다음

제1원칙을 지키려면 스위치 하나가 아니라 **급락 때 오르는 자산과의 분산**(채권·금·달러)과
**변동성 기반 비중 조절**이 필요하다(Moreira-Muir 2017 등). 버핏식 핵심(우량+저평가+저변동,
DART 재무 시점별)과 함께 별도 선언 후 같은 잣대로 잰다.

## 2차 선언 — 버핏식 핵심 + 위험 관리층 (측정 전, `lab_buffett.py`)

| 계열 | 규칙 | 격자 | 기본값 |
|---|---|---|---|
| D 위험관리 단독 | 5자산(KODEX200·나스닥100·국고채10년·금·달러) 역변동성 → 포트폴리오 변동성이 σ* 를 넘으면 비례 축소, 나머지 단기채권 ETF. 월말 | L 20·60·120일 × σ* 8·12·16% | (60, 12%) |
| E 버핏식 핵심 | 분기말, 그날 시총 상위 K(시점별) − 금융·증권·보험 − 거래대금 5억 미만 − 적자·자본잠식. 점수 = 평균(우량·저평가·저변동 순위), 상위 N 동일가중 | N 5·10·15·20 × K 100·200·350 | (10, 200) |
| F 버핏식+위험관리 | E 종목(K=200)을 월말마다 60일 변동성이 σ* 를 넘으면 축소, 나머지 국고채10년·금·달러(역변동성) | N 10·20 × σ* 10·15·20% | (10, 15%) |

- 우량 = 평균순위(영업이익/자산, 순이익/자본, −부채/자본) · 저평가 = 평균순위(순이익/시총, 자본/시총)
  · 저변동 = 순위(−252일 변동성).
- 재무는 DART 사업보고서, **공시일(접수번호 앞 8자리) 다음 날부터**만 쓴다(`dart_fundamentals.latest_as_of`).
- **데이터 한계(측정 전 확인)**: DART 다중회사 재무 API 는 2015 사업연도부터 — 2014 는 0건. 첫 재무는
  2016-03 공시라 **E·F 는 2016-03 말까지 현금**이다(박스권 구간 판정에 불리하게 작용). 우선주 13종은
  고유번호 매핑이 안 돼 제외. 수집 종목 수는 2015년 227 → 2025년 332(이후 상장 종목 증가).
- 판정은 1차와 같다: 기본값 ①~④ + 격자 중앙값 ①~④. 장기 스트레스는 데이터가 없어 해당 없음.

### 측정 사고 — 첫 E·F 결과는 무효

첫 실행은 재무가 **84종목**뿐인 파일로 돌았다. 앞서 실패해 중지한 수집 작업이 백그라운드 래퍼만 죽고
python 프로세스는 살아남아, 정상 수집(332종목) 파일을 자기 부분 데이터로 덮어썼다. 출력의
"재무 84종목" 으로 발견, 프로세스 종료 → 재수집 → 332종목 검증 후 재측정했다(위 표가 재측정).
재발 방지: `lab_buffett.MIN_FUND_CODES=250` 미만이면 실행 중단. 판정 기준·격자는 바꾸지 않았다.

### 읽는 법

1. **D 는 제1원칙을 가장 잘 지켰다**(MDD 7.8%, 최악 연도 −7.2%, MAR 0.88 — 지금까지 최고).
   하지만 수익이 연 6.9% 라 목표(21.8%)와 멀다. σ 격자가 결과를 거의 안 바꿨다 — 5자산 역변동성
   포트폴리오 자체 변동성이 이미 8% 미만이라 변동성 상한이 걸리지 않았다.
2. **버핏식 종목 선택은 이 구간 한국에서 지수보다 크게 못했다**(6.3% vs 16.8%). 2025~26 상승을
   삼성전자·SK하이닉스 같은 고변동 대형 성장주가 이끌었고, 저평가·저변동 종목은 소외됐다.
3. **F 의 변동성 조절은 낙폭을 줄이지 못했다.** 2017-08 → 2020-03 MDD 43.9%: 2018 의 완만한
   하락은 변동성이 낮아 비중이 100% 그대로였고, 2020-03 급락엔 60일 변동성이 늦게 반응했다.
   월말 동일가중 재조정이 하락 종목을 계속 사들여 E(분기)보다 낙폭이 컸다.

## 3차 선언 — 전략 조합 (측정 전, `lab_blend.py`)

제1원칙을 지킨 D 와 수익 목표를 넘은 B·C 를 섞는다. 구성요소는 **이미 측정한 기본값 그대로**.

| 조합 | 구성 | 격자 | 기본값 |
|---|---|---|---|
| G1 | α·C(듀얼모멘텀 12개월) + (1−α)·D(위험관리 L60·σ12%) | α 0.3·0.4·0.5·0.6·0.7 | 0.5 |
| G2 | α·B(레버리지+KOSPI>MA60) + (1−α)·D | α 0.2·0.3·0.4·0.5 | 0.3 |

구성요소 중 하나라도 새 비중을 내면 구성요소별 최신 비중을 α 로 가중합해 전체를 다시 맞춘다.
레버리지(비중 합 > 1) 없음. 판정은 같은 잣대(기본값 + 격자 중앙값). 장기 데이터 없음(채권·금·달러 ETF 2014-07~).

측정 전 예상(기록용): 구성요소의 MAR 최고치가 0.88(D)이라, 목표(CAGR 21.8%·MDD 20% → MAR ≥ 1.09)에
닿으려면 섞었을 때 MAR 이 구성요소보다 크게 올라야 한다. 통과 가능성은 낮다고 본다.

### 읽는 법
