# 대형주 추세추종 트랙 구현 (2026-06-08 ~ 06-11)

> 키움 자동매매 시스템에 종가매매와 **완전 별도 트랙**으로 추가된 대형주 추세추종 전략.
> 종가매매가 KOSPI 약세장 veto로 거래가 발생하지 않아 검증 불가 상태가 지속 → 시장필터·종가매수에
> 의존하지 않는 트랙을 신설. 종가매매 코드는 일절 수정하지 않음 (파일·state·로그·데몬·대시보드 전부 분리).

## 1. 전략 개요

- **철학 (블로그A)**: 손익비 1:3, 승률 낮아도 OK. 첫 목표(손절폭×3) 도달 시 30% 부분익절, 잔여분은 ATR 트레일로 추세 끝까지 보유. 시간청산·시장필터 없음.
- **진입 5조건 "차수재시실" (블로그B)**: 차트(MA200 우상향 + 횡보 후 장대양봉) / 수급(외인·기관 5일 순매수) / 재료(DART·뉴스) / 시황(주도섹터) / 실적(YoY). 백테스트는 point-in-time 가능한 차트+거래량+수급+RS 코어만 사용, 재료·실적은 라이브 가점/악재 veto로만 반영.
- **청산**: MA50 하방돌파 / 외국인 5일 순매도 전환 / ATR 트레일 이탈.

## 4. 라이브 데몬 (MOCK 운영 중) — `scripts/trend_follow.py`

**스케줄** (영업일):
| 시각 | phase | 동작 |
|------|-------|------|
| 08:50 | screen | 유니버스 스캔 → 게이트·점수 → 후보 선별 (+ 프리장 예상체결가·갭%) |
| 09:30 | entry | 동일비중 매수 (최대 5종목). 하락 중이면 보류 → 반등 시 진입, 10:30까지 미반등 시 그날 스킵 |
| 장중 | intraday | 주기적 트레일 갱신 + 첫목표 30% 부분익절 |
| 15:20 | exit | MA50 이탈 / 외인 순매도 전환 / 트레일 이탈 청산 |

**안전장치**: 주문 return_code 검증(유령 포지션 방지) · 단일 인스턴스 락 · exit_ledger net 손익 · 자정 회전 로그(30일) · events.jsonl · 텔레그램 알림 · 물타기 금지 가드(1종목 1진입) · 계좌 보유분 reconcile/ado6월16일 화요일이야. 자동매매 시작하자pt(수동 매수분 추세관리 편입).

**매매일지** (`data/trend_follow/journal.jsonl`): 진입/부분익절/청산 자동 기록(근거·손익비·보유일수 포함) + 수동 항목(심리상태/실수분석/개선점)을 대시보드 인라인 폼 또는 CLI로 기입.

**대시보드** (:8091): ① 보유 포지션(트레일 stop) ② 거래 내역(승률·payoff·net) ③ 매매일지 편집.
