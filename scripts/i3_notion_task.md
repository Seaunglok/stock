# 방어형 ETF 자동매매(I3) Notion 일일 기록 — 작업 지시 (headless claude 가 읽는다)

평일 15:50 판단·리그·분봉 수집 뒤 `scripts\i3_notion.cmd` 가 이 파일을 읽게 한다. 작성 규칙 전체는 `docs/notion-guide.md`.

**할 일은 DB 행 반영뿐이다.** 페이지(방어형 ETF 자동매매 대시보드·종합 정리·리그·연구)는 **편집하지 않는다** — 대시보드는 DB 로 가는
바로가기뿐이라 행만 넣으면 된다. 삭제·`replace_content` 금지. **중복 금지**(없는 행만 추가).
**값은 파일 그대로 쓴다 — 직접 계산하지 않는다.** 글자도 파일 그대로(줄임말을 풀거나 줄이지 않는다 — 파일이 이미
「풀네임(줄임말)」 규칙으로 만들어져 있다).

## ⚠️ 0. 인증 확인 (가장 먼저)
첫 Notion 도구 호출이 **인증 실패**(`OAuth session expired`, `Failed to authenticate`, 권한 오류)면 다른 말 없이
`결과: ❌ Notion 인증 만료 — 재인증 필요(반영 0건)` 한 줄만 출력하고 끝낸다. (2026-07 인증 만료 때 에이전트가
"성공"을 허위 출력해 몇 주간 누락이 숨겨진 사고가 있었다.) rate limit 등으로 중간에 멈추면 `결과: ❌ <원인>`.

## 1. 원천 파일
`data/i3/notion_sync.json` 을 Read 한다(직전에 `i3_notion_sync.py prep` 이 계산). 없으면 `결과: ❌ notion_sync.json 없음`.
구조: `since`(대조 시작일) · `daily`(일일 행) · `trades`(매매 행) · `months`(월 결산 행) · `warnings`.
각 행의 `key` 는 대조용이다 — **Notion 에 넣지 않는다.** 값이 `null` 인 속성은 넣지 않는다.

## A. 일일 기록DB — `collection://26cdda49-dc57-4939-bf5c-fbba413d50a2`
1. SQL 로 `"date:일자:start" >= since` 인 행의 `date:일자:start` 를 한 번에 조회한다.
2. `daily` 의 각 행 중 그 `일자` 가 DB 에 **없는 것만** 추가한다. 속성 이름은 파일 키 그대로
   (`날짜`=제목, `일자` → `date:일자:start` + `date:일자:is_datetime`=0, 나머지는 같은 이름). 숫자는 숫자로.
3. 이미 있는 날짜인데 `운용 자산` 또는 `누적(%)` 이 파일과 다르면 **고치지 말고** 결과 줄에 `불일치 N건(날짜)` 으로 보고.

## B. 주식 매매일지DB — `collection://63d8ae25-9910-4a36-ba3f-3dc942cb9733`
1. `trades` 가 비면 B 를 건너뛴다.
2. SQL 로 `매매이유 LIKE '🛡️ 방어형 ETF 자동매매(I3)%'` 이고 매수일자 또는 매도일자가 `since` 이후인 행을 조회한다.
3. 파일 행이 DB 에 **이미 있는지**: `매매구분`이 같고, 날짜(매수면 `매수일자`, 매도면 `매도일자`)가 같고, DB `종목명`에
   파일 행의 6자리 종목코드가 들어 있으면 **있음**. **없는 행만** 추가한다.
4. 추가할 때: 파일 속성 그대로 + `증권사`=키움증권. 날짜는 `date:매수일자:start`·`date:매도일자:start`(`is_datetime`=0),
   파일에 있는 날짜 필드는 모두 넣는다(매도 행엔 `매수일자`·`보유기간(일)`도 있다).
5. 이미 있는 행의 `체결단가`·`실현손익`이 다르면 고치지 말고 `불일치` 로 보고(증권사 체결가 정정 — 사람이 판단).

## C. 월별 결산DB — `collection://2c0f5ffd-e5d7-4587-a765-85ba9ec084dc`
`months` 의 각 행에 대해:
1. `월` 제목에 `🛡️ 방어형 ETF 자동매매(I3) YYYY년 M월` 이 들어 있는 행을 조회한다(추세추종의 `🤖 …` 행은 **건드리지 않는다**).
2. **있으면** `총 매수 금액`·`총 매도 금액`·`총 실현손익`·`총 매매 비용`·`월 수익률(%)` 을 파일 값으로 `update_properties`.
3. **없으면** 새 행 — `월`=파일의 `월`, 위 다섯 숫자.

## 마무리 — 결과 한 줄 (반드시 마지막 줄)
`결과: 일일 +N · 매매 +M · 결산 K 갱신` 형식. 불일치·`warnings` 가 있으면 뒤에 붙인다
(예: `결과: 일일 +1 · 매매 +2 · 결산 1 갱신 · 경고 1(체결가 미확인)`). 이미 다 있으면 `결과: 이미 반영됨 — 일일 0 · 매매 0 · 결산 1 갱신`.
