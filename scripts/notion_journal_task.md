# Notion 매매일지 자동 기록 작업 지시

오늘(KST) 추세추종 매매를 Notion에 기록한다. 중복 절대 금지.

## 절차
1. `docs/<오늘 YYYY-MM-DD>-trend-journal.md` 를 Read 로 읽는다. **파일이 없으면** 아무것도 하지 말고 `결과: 오늘 일지 없음` 만 출력하고 종료.
2. 일지의 **"매매 (신규 N · 청산 M …)" 표**를 본다.
   - **신규/청산이 0건이면** DB에 아무것도 추가하지 말고 `결과: 신규/청산 없음 — 스킵` 출력 후 종료.
3. 신규/청산이 있으면 먼저 **Notion 데이터소스** `collection://63d8ae25-9910-4a36-ba3f-3dc942cb9733`(주식 매매일지DB)에서 **매수일자가 오늘인 행**을 조회해 이미 기록된 종목을 파악한다.
4. 일지의 매매 종목 중 **아직 오늘자로 DB에 없는 것만** 추가한다(중복 금지):
   - 공통: `증권사`=키움증권, `매수일자`=오늘, `매매이유` 앞에 🤖 추세추종.
   - **신규 매수**: `매매구분`=매수, `체결단가`/`체결수량`/`총체결금액` 채움.
   - **청산**: `매매구분`=매도, `매도일자`=오늘, `실현손익`·`수익률(%)`·`체결단가`(청산가) 채움.
5. 끝나면 한 줄로 요약 출력 (예: `결과: 신규 2건 추가` / `결과: 이미 기록됨 — 스킵`).

## 금지
- 같은 종목을 오늘자로 **중복 추가 금지**.
- 일지 "보유 현황" 표의 종목은 추가하지 말 것 — **그날 신규 매수·청산만** 기록.
